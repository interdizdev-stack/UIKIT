# Дорожная карта UI KIT

Карта переводит аудит от 3 октября 2026 года в последовательные этапы. Она хранит
текущий статус, проверенные результаты и следующую задачу для продолжения после
сжатия контекста. Основная поставка остаётся библиотекой для HTML/PHP без обязательной
сборки на стороне подключающего проекта, с двумя темами и автономными примерами.

### Обычный репозиторий исходников

Ветка `main` содержит файлы самой библиотеки и каталога. После обычного
`git clone` каталог открывается через `file://` или `python3 scripts/serve.py`;
извлечение ZIP, установка пакетов и сборка не нужны. Архивы выпуска дополнительны,
а `agy audit.md` остаётся отдельным неотслеживаемым файлом пользователя.

Авторизация плагина не настраивает credentials локального Git. Для дальнейшего
обычного fetch/push используйте собственную авторизацию Git. Локальная история
сохранена; при импорте через плагин удалённые коммиты отличаются. Не заменяйте
удалённый main принудительно. По явному решению владельца от 2026-11-01
видимость репозитория сохраняется public. В main публикуется сама библиотека:
исходники, стили, скрипты, токены, ресурсы, зависимости, примеры и относящиеся
к UIKit документы/проверки. README описывает компоненты, подключение и правила.
Личные заметки, архивы истории, backups, credentials и результаты тестовых запусков
не публикуются; ZIP остаются только дополнительным форматом поставки.
Наличие GitHub-копии не меняет статус лицензий или временного названия библиотеки.
