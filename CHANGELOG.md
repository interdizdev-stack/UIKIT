# Изменения UI KIT

## 1.5.2 — 2026-11-01

- Меню select, searchable select и autocomplete учитывают ширину всех пунктов, отступы и галочку; короткие значения Light и 10/20 не дробятся, длинные ограничены viewport.
- Сообщение пустой таблицы целиком видно без горизонтальной прокрутки на телефоне.
- Выбранные значения select растут по высоте в узком поле; формы, timeline, графика и действия адаптируются к собственному контейнеру.
- Копируемые вкладки сохраняют интервалы чисел и подписей. Палитра и типографика получили переносимые стили, правильную тему палитры и рабочие ввод/сброс текста.
- Добавлены полный визуальный инвентарь, стресс-проверка длинного текста и состояний, проверки геометрии текста/меню в Chrome и Firefox.

## 1.5.1 — 2026-10-31

- Настройки preview помещаются в одну строку по ширине содержимого; убраны принудительные три/две колонки и отдельная полная строка выбора примера.
- Добавлен переносимый `brand-control-row`; короткие фильтры и поля toolbar не растягиваются автоматически. При нехватке места элементы переносятся с сохранением размеров controls.
- Приоритет одной строки закреплён в DESIGN.md, правилах разработки, шаблоне проекта и skill подключения; добавлены проверки заполнения строки и узких контейнеров.

## 1.5.0 — 2026-10-31

- Каталог разделён на основы, компоненты, композиции и страницы; 32 отдельные записи берут HTML из общих исходных шаблонов. Прежние deep links сохранены.
- Общий preview расположен первым; добавлены density, контейнер, применимые состояния и длинный текст. Полный HTML воспроизводит выбранные параметры, технические сведения свёрнуты.
- Добавлены матрица покрытия и рекомендации выбора, 305 системных проверок, расширенный Firefox smoke и 16 визуальных эталонов.
- Preview-сервер выдаёт DESIGN.md и комплект adoption, сохраняя запрет на приватные пути и листинги.

## 1.4.0 — 2026-10-31

- Добавлена автономная оболочка приложения с независимой рабочей областью, мобильной навигацией, list/detail/create/edit, настройками и подтверждениями.
- Примеры сохранения используют общий forms controller, сохраняют черновик после ошибок и более новые правки во время запроса; переход с изменённой формы требует решения пользователя.
- Добавлены вход/восстановление, 403/404/error/offline и законченный контентный сайт с поиском, просмотром материалов и формой связи.
- Три страницы копируются из каталога вместе с локальными обработчиками; callbacks подключают приложение без обязательного backend или нового runtime.

## 1.3.0 — 2026-10-31

- Сетки адаптируются к собственной ширине; table/list/auto разделяют состояние, выбор и фокус. Добавлены видимость колонок, sticky/pin и короткая пагинация.
- Мобильные фильтры, action sheet и детали используют общий drawer; responsive dialog, native select и сворачиваемые chips показаны в автономном/копируемом примере.
- Popup учитывает visualViewport; safe-area, coarse pointer и нижние закреплённые блоки согласованы с уведомлениями.
- Добавлены мобильные сценарии Chrome и опциональный фактический smoke Firefox; реальные телефоны остаются ограничением.

## 1.2.0 — 2026-10-31

- Добавлены переносимые page header/toolbar, группы действий, split action, native segmented/choice cards, description list и счётчик.
- Общий forms controller поддерживает необязательную сводку ошибок и серверные ошибки по именам полей, inline feedback и очистку при редактировании без потери значений.
- Опциональный ui-kit-patterns.js предоставляет copy с inline результатом и filter bar с draft/apply/cancel/reset, активными chips и scoped cleanup.
- Добавлены пять автономных/копируемых композиций, документация и проверки поведения, включая безопасный текст и позднее завершение copy после cleanup.

## 1.1.0 — 2026-10-31

- Согласованы минимумы 36/44/52 px для button, CTA, icon button, input/select и составных полей.
- Добавлена наследуемая плотность default/compact с собственными токенами, вложенными областями и передачей в popup; coarse pointer сохраняет минимум controls 44 px.
- Таблицы, списки, панели и skeleton используют плотность; убраны глобальные переопределения таблицы из catalog.css, ритм форм перенесён в общую библиотеку.
- Добавлены спокойные текстовые роли для рабочих экранов и автономный/копируемый пример плотности.
- Добавлены проверки размерного контракта, длинного текста, эмуляции pointer и совпадения каталога с копируемым HTML; расширена проверка схемы токенов.

## Документация и аудит — 2026-10-31

- Добавлены подробный аудит UX/UI версии 1.0.5, матрицы компонентов/состояний/плотности и мобильных сценариев, сравнение готовых систем и предложения по упрощению.
- Сохранены измерения и снимки, добавлен необязательный скрипт аудита для checkout и полного каталога.
- Этап 13 хранит результаты аудита; этапы 14–18 описывают предложенную последовательность реализации и ещё не начаты.
- Версия production-библиотеки остаётся 1.0.5: компоненты, токены и визуальные эталоны этим аудитом не изменяются.
