# Поддержка версии 1.5.2

Текущая поставка предназначена для HTML/PHP без обязательной сборки и внешнего CDN.
Bootstrap 5.3.8 и Lucide 0.468.0 vendored; модули подключаются по необходимости.

| Среда | Статус фактической проверки |
|---|---|
| Chrome 156.0.8078.47, Linux, отдельный headless профиль | Проверен: поведение, две темы, viewport, offline, fullscreen |
| 320 / 390 / 768 / 1440 CSS px | Проверены в эмуляции viewport |
| Reflow 200% / 400% | Проверен эквивалентный viewport 640/320 CSS px при физической ширине 1280, DPR 2/4 |
| Увеличение текста 200% | Проверено CSS-увеличение текста в формах и обратной связи |
| Text spacing / forced colors / reduced motion | Проверены сохранёнными сценариями |
| Firefox 159.0, Linux, изолированный headless профиль | 64 сочетания мобильных композиций и трёх страниц, 8 сочетаний preview, короткие фильтры, selection/chips, save/server errors и cleanup; программные действия |
| Safari | Пока не запускался |
| Реальные iOS / Android / сенсорные устройства | Пока не проверены |
| Screen reader NVDA / VoiceOver и другие | Пока не проверены |

Эмуляция reflow проверяет перестроение CSS и размеры документа; это не отдельная
проверка пользовательского меню zoom каждого браузера. AX-дерево и имена 20 реальных
Tab-остановок проверены, но AX-проверка не заменяет использование screen reader.
Точные результаты и окружение сохраняются в test-results/verification.json после запуска.

Клавиатура проверена для select/combobox, forms/stepper, выбора строк и страниц,
chips, drawer/modal, popover, toast/actions/retry, поиска и миниатюр/zoom галереи.
Открытые overlays сохраняют фокус и очищаются при destroy. Значения полей/выбор
сохраняются по документированным правилам. Контраст placeholder light и границ полей,
семантические цвета обеих тем покрыты отдельными измерениями. Проверки не являются
заявлением о полной сертификации WCAG: для рабочих страниц нужна также ручная проверка.

Text spacing применяет параметры из [W3C 1.4.12](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html):
line-height 1.5, интервалы после абзаца 2em, letter-spacing .12em и word-spacing .16em.
Reflow ориентируется на [W3C 1.4.10](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html).
Таблицы и preview имеют собственную подписанную горизонтальную область; документ
не прокручивается горизонтально. Forced colors скрывает необязательный декор,
сохраняет границы и focus. Reduced motion выключает loader/skeleton/transitions.

Нативные date/time, file dialog, drag/drop, fullscreen и системная тема зависят от
браузера/платформы. Fullscreen имеет обработку отказа; нативный pinch страницы сохраняется
при 100% в галерее, отдельный pinch масштаба картинки не реализован. Кнопки zoom/pan
и keyboard доступны. Телефон по умолчанию форматируется как ru; международный вариант
и opt-out описаны в API. Дополнительные locale/RTL/framework/TS/Figma задачи сохранены
в этапе 11 и не входят в текущую поставку.

Название и знак остаются временными; статус собственного лицензирования —
[license-status.md](license-status.md). Демо реквизиты, отзывы, условия и цифры не являются
реальными заявлениями. Приложение отвечает за сеть, валидацию на сервере, реальные тексты
политик и контент. UI KIT предоставляет интерфейс и события.

Плотность проверена в Chrome в двух темах/режимах на четырёх ширинах, включая
вложенную область, popup, input group и длинный текст. Эмуляция touch подтверждает
CSS coarse pointer и минимумы controls 44 px; это не фактический тест iOS/Android.
Размеры используют CSS lh для роста от текста; целевые современные браузеры нужно
проверить на страницах проекта, прежде чем расширять заявленную поддержку.

Уменьшенный visualViewport проверен в эмуляции, safe-area — контрактом CSS.
Системная клавиатура телефона и реальные вырезы экрана ещё не проверены.
Firefox smoke не включает trusted keyboard, fullscreen или screen reader.

Приёмка 1.5.0 дополнительно проверяет 12 представителей системы в 192 сочетаниях,
56 узких контейнеров с длинным текстом, применимые состояния preview и 64 реальных
перехода Tab рабочих страниц с AX-именами. Сохранены 16 визуальных эталонов
(2 темы × 2 плотности × 4 ширины), просмотренных до включения в regression.

Выпуск 1.5.1 прошёл 834 проверки Chrome и 82 Firefox. Для строк настроек добавлены
проверки заполнения без преждевременного переноса, двух тем/плотностей, собственных
контейнеров 240/320/660/1000 px, native/enhanced select и длинных подписей без пробелов.
Автономные фильтры и toolbar проверены без catalog.css; 16 visual — 0.000% diff.

Визуальная приёмка 1.5.2: 951 Chrome + 90 Firefox assertions, 117 новых проверок
геометрии, все 86 записей в 1376 сочетаниях и расширенный проход состояний/контейнеров.
Полное покрытие и исправления описаны в [отчёте 2026-11-01](visual-audit-2026-11-01.md).
Эталоны не менялись; ограничения реальных устройств и AT сохраняются.
