# Обновление UI KIT

## Переход на 1.5.2

Замените библиотеку целиком из текущего выпуска, включая CSS, ui-kit.js,
ui-kit-inputs.js и примеры. Обновите скопированные документы вкладок, палитры,
типографики и групп действий из каталога: их исходная разметка стала переносимой.
Меню может быть шире кнопки, сохраняя границы viewport; выбранный текст select
переносится по строкам и увеличивает высоту. Для узких вставок сайтных блоков
используйте существующий контейнер `brand-responsive`.

## Переход на 1.5.1

Короткие настройки и фильтры занимают ширину содержимого и переносятся по доступному
месту. `brand-filter-fields` использует flex вместо равных grid-колонок; поля toolbar
не растягиваются автоматически. Для подписанных настроек добавлен `brand-control-row`.
Проверьте локальные overrides grid/width/flex. Если длинному поиску необходимо заполнить
остаток строки, задайте ему отдельный проектный класс с обоснованной шириной/ростом.
Размеры текста, высоты controls и touch targets сохраняются.

## Переход на 1.5.0

Поставляйте CSS, JS и tokens из одной версии. Новые patterns и page recipes
подключаются по задаче. Table по умолчанию сохраняет scroll; auto/list, columns,
sticky/pin включаются явно. Multiselect показывает три тега и disclosure; если
нужны все теги, задайте data-choice-max-tags="0". Значения FormData не сокращаются.
На coarse pointer подписи выбора и цели checkbox таблицы имеют минимум 44 px;
закреплённая колонка учитывает их ширину. Проверьте свои локальные CSS overrides.

Копирование preview сохраняет выбранные density/container/state/long text.
Для начальной рабочей страницы выберите «Обычное» состояние и замените демонстрационные
callbacks своим приложением. Реальные устройства и AT проверьте отдельно по support.md.

## Переход на 1.1.0

Шкала controls теперь согласована: small/default/large — минимумы 36/44/52 px,
default в compact-контейнере — 36 px. Input/select раньше получались 47 px во всех
размерах; CTA и icon button теперь следуют общей высоте. Перепроверьте локальные
overrides высоты, padding и позиционирование иконок.

Для настройки области используйте `data-ui-density="default|compact"` и
`--ui-density-control-height`, `--ui-density-control-font-size`,
`--ui-density-control-padding-x`. Вертикальный padding рассчитывается от высоты
и текущей строки. Старые spacing-токены сохраняются, но `--ui-space-3` больше не
задаёт вертикальный padding всех полей. `spacing.compact` остаётся старым именем
для 20 px и не включает compact-режим.

Строки таблицы стали компактнее, labels читаются размером 14 px, обычная поверхность
не имеет обязательной тени. `.form-field` и `.brand-form` оформляются общей библиотекой;
удалите дублирующие межполевые отступы из проектного CSS, если они больше не нужны.
Копируемый пример и каталог используют одинаковые стили таблицы и формы.
Контракт и пример — [foundations.md](foundations.md).

Версия 1.0.0 завершает текущую HTML/PHP-поставку. Берите CSS, JS, vendor, fonts и tokens
из одного выпуска; перед заменой сохраните текущий проект. Не смешивайте модули разных
версий. Проверьте свои страницы после обновления: Bootstrap содержит глобальные стили.

Для перехода с 0.1.x прежние Bootstrap-классы, data-lightbox, телефонные поля и cookie
сохраняются. Новые модули подключаются после ui-kit.js только по необходимости.
Публичный API и зависимости находятся в [api.md](api.md), изменения — в
[CHANGELOG](../CHANGELOG.md). Более ранние catalog.js обработчики относятся к демонстрации;
используйте общую BrandUI.table/forms вместо копирования внутреннего каталога.

Если контент заменяется через AJAX, перед заменой ожидайте BrandUI.destroy(container),
после вставки вызовите BrandUI.init(container). Не очищайте DOM открытого overlay раньше
завершения destroy. Настройки data-native-select/multiple/size возвращают нативный select;
новый data-brand-choice включает расширенный поиск. Для stepper загрузите forms перед inputs.

Свои tokens меняйте в tokens.json и запускайте scripts/build-tokens.mjs. Прямые изменения
сгенерированного tokens.css/js будут потеряны при генерации. Собственные overrides CSS
держите отдельно после ui-kit.css; проверяйте обе темы и nested theme. Default типографика,
границы и placeholder с 0.2.0 используют дополнительные семантические роли.

WOFF2 выбирается первым, TTF остаётся fallback. Subset Lucide подходит для стандартных
примеров; произвольные иконки требуют полного lucide.min.js либо обновлённого subset.
Выберите один script, не загружайте оба. Подробнее — [performance.md](performance.md).

Перед выпуском проекта проверьте фактические сценарии и браузеры его аудитории;
подтверждённое окружение библиотеки перечислено в [support.md](support.md).
