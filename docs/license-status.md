# Статус лицензий

Собственная лицензия UI KIT пока не выбрана владельцем. Версия 1.0.0 и статус готовности
компонентов описывают реализацию/проверки; они не назначают автоматически MIT, ISC или
другую лицензию собственному коду, SVG, текстам и референсам. Название Brand UI и знак
остаются временными. Решение об утверждении и распространении сохранено в O05 этапа 11.

В поставке сохранены лицензии зависимостей:

| Ресурс | Файл лицензии |
|---|---|
| Bootstrap 5.3.8 | vendor/bootstrap-LICENSE.txt |
| Lucide 0.468.0, включая generated subset | vendor/lucide-LICENSE.txt |
| Manrope TTF/WOFF2 | assets/fonts/manrope-OFL.txt |
| Oswald TTF/WOFF2 | assets/fonts/oswald-OFL.txt |

Исходные TTF и референсы сохраняются. Новые WOFF2 получены преобразованием формата,
без удаления глифов; проверены name/вариации/контуры. Их OFL-файлы находятся рядом.
Генераторы FontTools/Brotli нужны только maintainer для повторного преобразования,
не включаются в runtime библиотеки и не меняют статус собственного кода.
