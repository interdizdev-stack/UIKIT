# Каталог и перенос примеров

[Открыть каталог](../index.html) · [Подключение и API](../index.html#integration) ·
[Иконки](../index.html#icons) · [Полный ZIP](../ui-kit-catalog.zip).

Каталог имеет четыре уровня: основы, компоненты, композиции и страницы.
Каждый раздел начинается блоком «Пример и подключение». Выберите пример,
посмотрите свойства, состояния и список файлов. «Копировать полный HTML» и
«Скачать HTML» дают автономный документ с CSS, JS и демонстрационными обработчиками.
Расположите его рядом с ui-kit.css в распакованной библиотеке, сохранив vendor,
assets и examples. Для референсов нужны assets/references из полного каталога.
Кнопки «Копировать HTML» у отдельных образцов оставляют короткий фрагмент; для полного
подключения используйте общий блок. Код берётся из исходных шаблонов, до init.
В нём нет generated select-wrapper или уже подменённых SVG вместо data-lucide.

Настройки preview используют `brand-control-row`: ширина по содержимому, одна строка,
пока хватает места, и перенос целых полей при сужении контейнера. Отдельных принудительных
колонок для desktop/mobile нет; размер текста и высота controls сохраняются.

Демонстрационные handlers находятся в examples/catalog-demo.js и указанных файлах
examples/*.js; catalog.js и catalog.css для скопированной страницы не нужны.
В проекте можно заменить их собственными callbacks. FormData/запросы обрабатывает
приложение; примеры форм/загрузки не отправляют данные. Cookie preview использует
persist:false и не подключает аналитику. Перед рабочим подключением задайте политику,
storageKey и onChange согласно [API](api.md). Статичные блоки могут использовать только CSS.

Preview расположен в iframe. Выбор 320/390/768/1440 px меняет реальную ширину документа,
поэтому media queries и matchMedia работают как в самостоятельной странице. Если
viewport шире каталога, прокручивается только область preview. Тема preview выбирается
независимо: Light или Dark. Высота окна ограничена, внутренний документ прокручивается.
Плотность default/compact независима от темы. Контейнер 240/320/480 px ограничивает
содержимое внутри viewport: это отдельная проверка, не эмуляция экрана. Для полных
страниц и навигации Bootstrap с viewport-breakpoint поле контейнера отключено;
используйте ширину viewport. Длинный текст добавляет пояснения без удаления
интерактивной разметки. Применимые состояния меняют настоящие контроллеры/атрибуты,
а недоступные состояния не предлагаются.

При смене примера, темы, плотности, контейнера или состояния создаётся новый документ;
старый iframe-контекст очищается. Простая смена viewport меняет ширину существующего
документа, сохраняя выбор. Копирование/скачивание сохраняет выбранные параметры.
Свойства и зависимости свёрнуты под preview.

Ссылки имеют вид `#раздел/пример`: например
[Stepper](../index.html#advanced-forms/advanced-5),
[Hero](../index.html#site-blocks/site-hero),
[Таблица](../index.html#tables/table),
[Gallery](../index.html#lightbox/gallery). Выбор примера обновляет fragment без перезагрузки;
кнопка «Прямая ссылка» даёт текущий адрес. Неизвестный раздел открывает кнопки,
неизвестный пример — первый в разделе. Поиск работает на настольном и мобильном экране,
находит разделы и отдельные примеры. Down/Up/Home/End перемещают фокус по результатам,
Enter открывает ссылку, Escape закрывает список и возвращает фокус к поиску.

В [иконках](../index.html#icons) доступны поиск по имени, страницы по 48 иконок,
размеры 16/24/32/48 px и HTML-копирование. Точное имя из vendored Lucide передаётся
в data-lucide. У отдельной смысловой иконки role=img и aria-label; декоративная имеет
aria-hidden=true. У icon-only кнопки подпись задаётся на button, вложенный SVG остаётся
декоративным. Размер сохраняется через inline width/height, чтобы общий стиль Lucide
не переопределял его. Можно скопировать фрагмент либо полный документ общего inspector.

Свойства описывают доступные настройки; состояния показываются в примере или включаются
его действиями (загрузка/retry/выбор/открытие). Hover/focus проверяйте реальной мышью
и клавиатурой; disabled/loading имеют нативный disabled и aria-busy. Перечень не означает,
что любой атрибут применим ко всем компонентам: следуйте документации соответствующего модуля.
[Правила компоновки](site-blocks.md), [основы](foundations.md), [поля](inputs.md),
[обратная связь](feedback.md) и [компоненты](components.md) помогают выбрать нужный вариант.

Значок preview показывает уровень системы, а проверенные среды перечислены в
[support.md](support.md). Chrome проходит полный набор; Firefox — ограниченный
фактический smoke. Реальные устройства и screen reader отмечаются проверенными
только после фактической проверки. Итоговые данные выпуска находятся в ROADMAP.md и CHANGELOG.md.
Название, знак и собственная лицензия остаются решением владельца проекта.

При размещении полного каталога на хостинге положите ui-kit-catalog.zip рядом с index.html,
чтобы ссылка скачивания работала. Архив не может содержать сам себя; распакованная
версия содержит библиотеку ui-kit.zip, а полный ZIP размещается отдельным файлом.

[Матрица покрытия и правила выбора](system-coverage.md) связывает базовые элементы,
композиции, страницы и оставшиеся ограничения аудита.
