# Блоки сайта и графика

[Автономный пример](../examples/site-blocks.html) показывает 14 секций в light/dark.
Они используют Bootstrap CSS, tokens.css и ui-kit.css. Статичные секции работают без JS;
ui-kit.js + Lucide добавляют SVG-иконки, ui-kit-forms.js — проверку и состояние форм.
Bootstrap JS нужен окружающим modal/drawer, не нативному FAQ.

| Блок | Применение |
|---|---|
| hero | Одно предложение, основной CTA и иллюстрация; на узком экране одна колонка |
| features | Три конкретных преимущества с иконкой и объяснением |
| services | Форматы работы с составом и отдельным действием |
| steps | Нумерованные шаги, семантический ol |
| timeline | События с датами time/datetime и вертикальной линией |
| cases | Задача, решение, иллюстрация и проверяемый результат |
| testimonials | blockquote/figcaption, подпись автора и avatar |
| trust | Подписи партнёров; заменяйте разрешёнными к публикации знаками |
| comparison | Таблица форматов с caption, scope и отдельной прокруткой |
| statistics | Крупные числа в dl, подпись единицы/смысла |
| promo | Повтор основного CTA с коротким объяснением |
| faq | Нативные details/summary с клавиатурой; вопросы раскрываются независимо |
| contact | Контакты, короткая заявка и форма с описанием задачи |
| graphics | Мазок, стрелка, рамка, точки и текстура из assets/graphics |

Пример компоновки: hero → преимущества → услуги → этапы → кейс → подтверждения →
условия → FAQ → контакт. Выбирайте секции по вопросам посетителя. Не размещайте все
варианты ради заполнения страницы и не повторяйте несколько равнозначных главных CTA.
Референсы показывают последовательность «понять → сравнить → убедиться → действовать»;
[исходные материалы](../index.html#references) сохранены без изменений.

HTML копируется по блоку из [каталога](../index.html#site-blocks). Контактные anchors
должны совпадать с ID ваших секций. В примере prefix=site задаёт site-contact и site-cases.
Повторяя блок, замените ID полей/labels/anchors либо передайте новый prefix фабрике:

```js
const html = BrandUISiteExamples.markup('hero', {
  prefix: 'landing', assetBase: 'assets/'
});
```

Фабрика находится в examples/site-blocks.js и нужна только для генерации примеров.
Скопированный статичный HTML не требует фабрики. В каталоге уже есть H1; первый экран
использует H2. На рабочей странице сделайте главный заголовок H1 с сохранением класса.
Изображения имеют width/height и содержательный alt. Декор имеет aria-hidden и
pointer-events:none. Не используйте стрелку как единственное обозначение действия.

Формы примера проверяют поля локально и показывают результат без отправки.
`BrandUISiteExamples.setup(container)` подключает только демонстрационный callback.
Рабочее приложение использует `BrandUI.forms.init(form, {onSubmit})`, обрабатывает
FormData/AbortSignal и показывает следующий шаг; см. [API форм](api.md).
Текст о данных и контактные реквизиты заменяет владелец проекта. Email example.com,
отзывы «Имя клиента», условия и показатели в примере не являются реальными заявлениями.

## Декоративные материалы

В assets/graphics лежат brush.svg, arrow.svg, frame.svg, dots.svg, texture.svg и
interface-preview.svg. Это самостоятельные векторные приёмы по мотивам референсов:
мазок сухой кисти и стрелка с широким рисованным наконечником, зернистая фактура
и рваные края по мотивам исходных брендовых изображений, открытые углы, точечная сетка
и тонкая текстура. Контуры и прозрачные просветы brush/arrow перенесены из
06-signs.png и 02-consultation.png соответственно, без растровых вставок в SVG.
Они не являются утверждённым знаком или логотипом. Brand UI — временная подпись набора.
Лицензия собственного кода/новых SVG остаётся решением владельца; лицензии зависимостей
и шрифтов сохранены в vendor и assets/fonts.

CSS-класс `.brand-graphic` окрашивает SVG-mask в --ui-accent-text нужной темы. Суффиксы
--brush/--arrow/--frame/--dots/--texture выбирают материал. Размер задаётся width/height,
цвет — color; внешние SVG остаются чёрными масками. `.brand-marked` подчёркивает короткий
фрагмент заголовка. Убирайте декор, если он мешает чтению, пересекает контролы или
усложняет маленький экран. Для крупного фона используйте низкую opacity и сохраняйте
контраст текста; декор не несёт обязательной информации. В forced colors декор скрыт,
числа и подписи остаются. Анимации в этих секциях не добавлены.

ZIP должен содержать assets/graphics рядом с ui-kit.css: CSS-mask использует относительные
пути от CSS. Для собственных картинок меняйте src/alt, не используйте референс с текстом
вместо HTML контента. На мобильном comparison прокручивается внутри подписанной области;
остальные секции переходят в одну или две колонки без прокрутки документа.
